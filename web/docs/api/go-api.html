Go API

Go API

github.com/henomis/phero

github.com/henomis/phero

a2a

Package a2a exposes phero agents as A2A servers and lets agents call remote A2A endpoints as tools.

github.com/henomis/phero/a2a

agent

Package agent provides a small orchestration layer around an llm.LLM.

github.com/henomis/phero/agent

document

Package document defines the Document type returned by text splitters.

github.com/henomis/phero/document

embedding

Package embedding defines a small, provider-agnostic interface for generating vector embeddings from text.

github.com/henomis/phero/embedding

embedding/openai

Package openai provides an OpenAI-backed Embedder implementation.

github.com/henomis/phero/embedding/openai

llm

Package llm provides small, composable building blocks for driving LLM-backed applications.

github.com/henomis/phero/llm

llm/anthropic

Package anthropic provides an llm.LLM implementation backed by Anthropic's Messages API.

github.com/henomis/phero/llm/anthropic

llm/middleware

Package middleware provides built-in llm.Middleware implementations for the phero framework.

github.com/henomis/phero/llm/middleware

llm/openai

Package openai provides an llm.LLM implementation backed by the OpenAI Chat Completions API.

github.com/henomis/phero/llm/openai

mcp

Package mcp provides adapters for working with the Model Context Protocol (MCP) in this codebase.

github.com/henomis/phero/mcp

memory

Package memory defines the Memory interface for conversational context storage.

github.com/henomis/phero/memory

memory/jsonfile

Package jsonfile provides a file-backed message store for agents.

github.com/henomis/phero/memory/jsonfile

memory/nats

Package natsmemory implements the memory.Memory interface using NATS JetStream Key-Value.

github.com/henomis/phero/memory/nats

memory/psql

Package psql implements the memory.Memory interface using PostgreSQL.

github.com/henomis/phero/memory/psql

memory/rag

Package rag provides a memory.Memory implementation backed by the project's retrieval-augmented generation (RAG) store.

github.com/henomis/phero/memory/rag

memory/simple

Package simple provides a small in-memory message store for agents.

github.com/henomis/phero/memory/simple

nats

Package nats implements the NATS Agent Protocol v0.3 for Phero agents.

github.com/henomis/phero/nats

rag

Package rag provides a small retrieval-augmented generation (RAG) helper.

github.com/henomis/phero/rag

skill

Package skill provides helpers to discover and parse skill definitions.

github.com/henomis/phero/skill

textsplitter

Package textsplitter defines the shared abstractions for text splitting.

github.com/henomis/phero/textsplitter

textsplitter/markdown

Package markdown provides a Markdown-aware text splitter.

github.com/henomis/phero/textsplitter/markdown

textsplitter/recursive

Package recursive provides a recursive character-based text splitter.

github.com/henomis/phero/textsplitter/recursive

tool/agent

Package agent provides a reusable tool wrapper for delegating tasks to another runnable agent.

github.com/henomis/phero/tool/agent

tool/bash

Package bash provides a Phero tool that executes bash commands on behalf of an LLM agent.

github.com/henomis/phero/tool/bash

tool/file

Package file provides filesystem-oriented tools aligned with read/write/edit/glob/grep naming.

github.com/henomis/phero/tool/file

tool/human

Package human provides a structured user interaction tool for agents.

github.com/henomis/phero/tool/human

tool/skill

Package skill provides a dispatcher tool that loads SKILL.md instructions into the current conversation.

github.com/henomis/phero/tool/skill

trace

Package trace provides observability hooks for phero agents and LLM calls.

github.com/henomis/phero/trace

trace/jsonfile

Package jsonfile provides a file-backed Tracer that persists trace events as newline-delimited JSON (NDJSON).

github.com/henomis/phero/trace/jsonfile

trace/otel

Package otel provides an OpenTelemetry-backed trace.Tracer that maps phero agent, LLM, and tool events onto OpenTelemetry spans.

github.com/henomis/phero/trace/otel

trace/text

Package text provides a human-readable, colour-coded Tracer implementation that writes one formatted line per event to an io.Writer.

github.com/henomis/phero/trace/text

vectorstore

Package vectorstore defines the Store interface for vector search backends.

github.com/henomis/phero/vectorstore

vectorstore/psql

Package psql implements the vectorstore.Store interface using PostgreSQL + pgvector.

github.com/henomis/phero/vectorstore/psql

vectorstore/qdrant

Package qdrant implements the vectorstore.Store interface using Qdrant.

github.com/henomis/phero/vectorstore/qdrant

vectorstore/weaviate

Package weaviate provides a Weaviate-backed vectorstore.Store implementation using the official Weaviate Go client (v4).

github.com/henomis/phero/vectorstore/weaviate
